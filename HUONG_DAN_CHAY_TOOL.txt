================================================================================
          HƯỚNG DẪN SỬ DỤNG TOOL TẢI ÁNH TỰ ĐỘNG THEO CATEGORY
================================================================================

1. GIỚI THIỆU TOOL:
   - Tool `download-images.js` sẽ tự động đọc 3 file JSON dữ liệu sản phẩm:
     + packages/data/json/products-20.json
     + packages/data/json/products-500.json
     + packages/data/json/products-2000.json
   - Quy tắc tải ảnh:
     + Tải 1 ảnh chính (ưu tiên `thumbUrl`, nếu không có sẽ lấy `detailUrl`).
     + Tải toàn bộ ảnh trong mảng `gallery`.
     + Đổi tên/Giữ nguyên tên file ảnh tải về TRÙNG KHỚP 100% với tên file quy định trong JSON URL (Ví dụ: `dien-thoai-thong-minh-vivo-nova-x12-pro-101.webp`, `dien-thoai-thong-minh-vivo-nova-x12-pro-101-a.webp`).
   - Thư mục lưu ảnh tải về: `packages/data/assets/raw/<category-slug>/`

2. YÊU CẦU TIỀN ĐỀ:
   - Máy tính đã cài đặt Node.js (phiên bản 18 trở lên).
   - Tool sử dụng API chuẩn của Node.js (fetch, fs, path), không cần cài đặt thêm bất kỳ thư viện npm bên ngoài nào.

3. HƯỚNG DẪN CÁCH CHẠY TOOL:

   Bước 1: Mở Terminal (PowerShell / Command Prompt / Git Bash / VS Code Terminal).
   
   Bước 2: Di chuyển (cd) vào thư mục gốc dự án (nơi chứa file `download-images.js` và folder `apps`).
           Ví dụ:
           cd "C:\Users\Admin\OneDrive\Máy tính\web-vitals-csr-vs-ssr"

   Bước 3: Chạy lệnh sau để bắt đầu tải ảnh:
           
           node download-images.js

4. TÍNH NĂNG CỦA TOOL:
   - Lọc trùng URL: Tự động gom tất cả ảnh thumbUrl và gallery, loại bỏ các ảnh trùng lặp.
   - Giữ nguyên tên file JSON: Tên file lưu tại local hoàn toàn trùng với tên file ảnh trong URL JSON.
   - Tải song song thông minh: Tải 15 ảnh cùng lúc để đạt tốc độ tối đa mà không bị nghẽn.
   - Tự động bỏ qua (Skip): Nếu ảnh đã tồn tại trong folder local, tool sẽ tự bỏ qua không tải lại.
   - Thử lại khi lỗi (Retry): Thử tải lại tối đa 3 lần nếu gặp sự cố mạng chập chờn.
   - Báo cáo tiến độ chi tiết theo số phần trăm và thời gian thực hiện.
